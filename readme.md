## 📌 Sobre o Projeto

Essa landing page foi desenvolvida para **Extreme Gamer Informática** , uma loja de hardware de alta performance e assistência técnica especializada localizada em **Feira de Santana, Bahia**. 

O projeto foca em entregar uma experiência visual moderna (*Dark/Gamer Aesthetic*), destacando os grandes diferenciais da marca: **2 Anos de Garantia Premium**, montagens sob medida com cable management cirúrgico, peças originais selecionadas e suporte técnico direto de bancada.

A interface foi projetada e implementada  garantindo ergonomia visual, alta taxa de conversão e total responsividade para computadores, tablets e smartphones.

## 🖥️ Como Visualizar e Executar

1. Clone o repositório ou baixe os arquivos para o seu computador:
   ```bash
   git clone https://github.com/lucca3447/pcgamingstore.git
   ```
2. Abra a pasta do projeto e navegue até `frontend/`:
   ```bash
   cd pcgamingstore/frontend
   ```
3. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Opera ou Safari) com duplo clique ou utilizando a extensão **Live Server** no VS Code.
4. Para testar a responsividade, utilize as Ferramentas do Desenvolvedor (`F12` ou `Ctrl + Shift + I` no Windows) e alterne a emulação entre Computador, iPad/Tablet e iPhone/Android.
